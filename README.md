# 📊 Excel Sales Analysis Project – AtliQ Hardwares  

## 🧩 Project Objective  

**1.** Build a comprehensive [Sales Analysis Report](./Sales_Analysis_report.pdf) summarizing overall business performance.  

**2.** Compare [Market Performance vs Sales Targets](./Market_vs_target_report.pdf) to measure goal achievements.  

**3.** Create a [Division Level Report](./Division_Level_report.pdf) showing YoY growth from 2020 to 2021.  

**4.** Identify [Top & Bottom 5 Products by Quantity](./Top_and_Bottom_5_qty.pdf).  

**5.** Analyze [Top 10 Products](./Top_10_Product.pdf) and [Top 5 Countries](./Top_5_Country_21.pdf) driving sales.  

**6.** Highlight [New Products Launched in 2021](./New_Products_21.pdf) and their contribution to growth.  

---

## 📝 Project Description  

This project delivers a complete **sales performance analysis** for *AtliQ Hardwares* using **Microsoft Excel**.  
The goal is to evaluate **sales growth, customer trends, product demand, and market achievements** through dynamic dashboards and detailed reports.  

The analysis compares sales between **2020 and 2021**, identifies **top-performing divisions and products**, and measures how well the company achieved its **market targets**.  

The project demonstrates how **raw transactional data** can be transformed into **clear business insights** using Excel’s analytical tools.

✅ **Total Sales Growth:** +304.5%
